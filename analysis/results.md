# Results

This portfolio screening combines distance to curated historical earthquake reference points with a population-proxy rank. It is intentionally not presented as an official seismic hazard model.

## Official-data upgrade

J-SHIS provides 250 m probabilistic seismic hazard information, scenario shaking maps, site amplification factors, and exposed-population data. The repository documents the official API and the `T30_I45_PS` attribute for integration.
