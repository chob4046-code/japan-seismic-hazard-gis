# Data Dictionary

| Dataset | Geometry | Key fields / outputs | Purpose |
|---|---|---|---|
| Seismic hazard | Polygon mesh | hazard probability/intensity | Primary hazard indicator |
| Site amplification | Polygon mesh | amplification factor | Ground-condition indicator |
| Faults | Line | fault/source identifiers | Context and proximity |
| Population | Polygon/grid/points | population count | Human exposure |
| Roads | Line | road class | Infrastructure exposure |
| Railways | Line | railway class | Infrastructure exposure |
| Critical facilities | Point | facility type | Emergency-service exposure |
| Administrative boundaries | Polygon | area identifiers | Reporting and map context |

## Metadata to record

For every downloaded dataset record:

- source organization
- dataset title
- URL
- download date
- version/reference year
- CRS
- license/terms
- processing steps
