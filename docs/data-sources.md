# Data sources

## J-SHIS / NIED

The final seismic analysis should use official J-SHIS data where appropriate. J-SHIS provides probabilistic seismic hazard map data, scenario-earthquake shaking map data, fault coordinates/parameters, site amplification factors, subsurface information, and exposed-population statistics.

Official portal: https://www.j-shis.bosai.go.jp/en/downloads

## Natural Earth base layers

The starter QGIS project also uses public-domain Natural Earth 1:50m country boundaries and populated places as geographic reference layers.

## Data integrity

Do not interpret the starter project as an earthquake prediction model. Final hazard/exposure results must identify the J-SHIS dataset/version, processing date, CRS, and any assumptions or weighting choices.
